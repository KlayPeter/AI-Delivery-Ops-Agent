## 文档维护规则

- 用户可见行为变化时，更新用户指南和对应 `FEATURE.md`。
- 配置项、环境变量或权限变化时，更新第三方平台接入指南和 `.env.example`。
- 部署、数据或安全边界变化时，更新根 README、部署文档和 `SECURITY.md`。
- 示例只使用虚构名称、占位 ID 和测试地址。
- 禁止写入真实凭据、人员信息、内部域名、私有项目链接或生产日志。

代码与测试是运行行为的最终事实源。文档与代码冲突时，应先确认实际行为，
再在同一变更中修正文档。
