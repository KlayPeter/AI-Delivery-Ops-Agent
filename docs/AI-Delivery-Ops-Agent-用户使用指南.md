# AI 交付助理用户指南

AI Delivery Ops Agent（中文名：AI 交付助理）把飞书消息、TAPD 任务、
站会、日报、周报、看板和 AI 资讯放到同一套可审计的工作流中。

本文使用虚构的 `Demo Project`、`Demo 研发组` 和示例成员。部署者必须用
自己的测试账号完成配置，并遵守所在组织的数据与权限规则。

## 使用前提

- 管理员已经配置飞书应用、TAPD Workspace 和模型提供方。
- 机器人已加入目标群，并订阅 `im.message.receive_v1`。
- 群成员和功能开关已经在系统配置页保存。
- 管理页面只通过可信网络或带身份验证的反向代理开放。

## 在群聊中使用

### 创建任务

在群里明确描述任务、负责人和截止日期：

```text
@AI 交付助理 创建任务：完成演示项目的发布检查，负责人 @王开发，周五前完成
```

系统会解析任务信息并通过领域服务写入 TAPD。缺少必要信息时，机器人会
追问；它不会让模型直接绕过任务规则写数据库。

### 更新任务状态

可以引用机器人发出的任务消息并回复：

```text
已开始开发
遇到阻塞，需要接口说明
开发完成
```

引用上下文优先于文本猜测。若同时出现多个可能任务，请显式提供任务 ID。

### 站会

成员可在私聊或已配置群中提交：

```text
昨天：完成接口联调
今天：补充自动化测试
阻塞：暂无
```

系统按群配置收集成员状态，定时提醒缺失成员，并生成群级汇总。

### 日报、周报与看板

```text
@AI 交付助理 生成今天的日报
@AI 交付助理 生成本周周报
@AI 交付助理 生成最新项目看板
```

否定表达不会触发生成，例如“不要生成日报”。历史快照只能从当前群和允许
的路径读取。

### AI 热点新闻

默认机器人私聊支持：

```text
今天 AI 圈有什么热点
最近三天 OpenAI 的新闻
搜索 Claude
来源 机器之心
AI 信号
查看更多
```

默认返回 15 条；“查看更多”续取下一批最多 20 条。新闻能力默认复用现有
机器人，也可以由管理员配置独立新闻机器人。外部资讯来自配置的公共
Provider，原文和图片权利属于各来源。

## 管理控制台

控制台包含：

- 进度看板与人力甘特图；
- 审计日志与上下文记录；
- 站会和周报归档；
- 手动触发与调试入口；
- 群、成员、集成参数和定时计划配置。

配置保存成功表示数据已经持久化。Scheduler 会在下一次重载周期使用新配置，
并不表示对应业务任务已经执行。

## 多机器人和 Agent

系统按 Workspace、Bot Instance、Agent Installation 和 Capability 隔离路由。
默认内置：

- Delivery Ops 主 Agent；
- Task Agent；
- Standup Agent；
- Daily Summary Agent；
- Weekly Report Agent；
- Project Dashboard Agent；
- AI News Radar Agent。

主 Agent 可以委派专业 Agent，但委派深度、超时、输出大小、Tool 和 Skill
都受 Manifest 与 Runtime 约束。

## 常见问题

### 机器人没有回复

检查飞书长连接是否健康、应用 ID 是否匹配当前 Bot Instance、消息是否来自
允许的群或私聊，以及事件是否被幂等过滤。

### TAPD 操作失败

检查 `TAPD_WORKSPACE_ID`、Token、Workitem Type ID 和 API 权限。公开版默认
Workspace 为 `0`，不会自动连接真实项目。

### 模型不可用

确认 `AI_PROVIDER`、`AI_API_BASE`、`AI_API_KEY` 和 `AI_MODEL`。确定性任务、
站会和路由能力应继续工作；需要模型的请求会返回可解释错误。

### 能否直接暴露公网

不能。当前应用没有内置鉴权。请在可信网络中使用，或通过带登录、TLS、
限流和访问审计的反向代理保护。

## 数据与隐私

- 不要把凭证、客户数据或生产日志提交到仓库。
- `.env`、SQLite、日志、备份和生成报告都应留在受控运行环境。
- 审计日志默认保留 90 天，可通过维护配置调整。
- SQLite 只支持一个后端写实例；备份数据库前应遵循一致性要求。
